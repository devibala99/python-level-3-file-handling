# Log File Analyzer

## Description
A simple Python CLI tool to analyze application log files.

## Features
- Reads log files line by line
- Counts INFO, WARNING, and ERROR messages
- Extracts error messages
- Generates a summary report file

## Files
- `main.py` – Application entry point
- `analyzer.py` – Log analysis logic
- `sample.log` – Input log file
- `report.txt` – Generated report

## How to Run
```bash
python main.py
