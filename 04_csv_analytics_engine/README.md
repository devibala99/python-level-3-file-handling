# CSV Analytics Engine

## Description
A Python program that analyzes sales data from a CSV file and generates a business summary report.

## Features
- Reads CSV sales data
- Calculates total revenue
- Aggregates revenue by category
- Aggregates revenue by region
- Writes analytics report to a file

## Files
- `main.py` – Program entry point
- `analytics.py` – Business logic
- `sales.csv` – Input data
- `report.txt` – Generated output

## How to Run
```bash
python main.py
