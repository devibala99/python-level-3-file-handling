# Config Driven Application

## Description

A simple Python application where behavior is controlled using a configuration file.

## Features

- Reads configuration from JSON
- Enables or disables features at runtime
- No code changes required to modify behavior

## Files

- `main.py` – Application entry point
- `config_loader.py` – Loads configuration
- `features.py` – Feature logic
- `config.json` – Configuration file

## How to Run

```bash
python main.py
```
