# Stateful Workflow Engine

## Description

A Python application that manages ticket lifecycle using predefined state transitions.

## Features

- Create tickets
- Track ticket states
- Enforce valid workflow transitions
- Persist data using JSON

## Files

- `main.py`
- `ticket_service.py`
- `workflow.py`
- `storage.py`
- `tickets.json`

## How to Run

```bash
python main.py
```
